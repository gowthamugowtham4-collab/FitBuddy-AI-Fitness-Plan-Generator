# Phase 2 – Requirement Analysis

## 1. Functional Requirements

### User Input
The system should allow users to enter:
- Name
- Age
- Weight
- Height
- Fitness level
- Fitness goal

### Fitness Plan Generation
The system should send the user's requirements to the Gemini model and generate a personalized fitness plan.

### Workout Plan
The system should provide suitable workout recommendations based on the user's fitness goal and fitness level.

### Plan Display
The generated fitness plan should be displayed clearly to the user.

## 2. Non-Functional Requirements

- The application should be easy to use.
- The application should provide results within a reasonable time.
- User input should be validated.
- The application should handle errors properly.
- The system should protect API credentials.

## 3. Hardware Requirements

- Computer/Laptop
- Minimum 4 GB RAM
- Internet connection

## 4. Software Requirements

- Python
- FastAPI
- Gemini API
- HTML
- CSS
- GitHub
- Web browser

## 5. Users

The main users of FitBuddy are:
- Fitness beginners
- Students
- People looking for personalized fitness guidance

## 6. Expected System Output

The system should generate a personalized fitness plan based on the user's:
- Age
- Weight
- Height
- Fitness level
- Fitness goal
