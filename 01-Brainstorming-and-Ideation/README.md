# FitBuddy – AI Fitness Plan Generator using Gemini Models

## 1. Problem Statement
Many people find it difficult to create a personalized fitness plan based on their age, weight, fitness level, and fitness goals.

## 2. Proposed Solution
FitBuddy is an AI-based fitness plan generator that uses Gemini models to generate personalized fitness plans based on the user's information and fitness goals.

## 3. Target Users
- Fitness beginners
- Students
- People who want personalized workout plans
- Users who want basic fitness guidance

## 4. Key Features
- User details input
- Fitness goal selection
- AI-generated personalized fitness plan
- Workout recommendations
- Easy-to-use interface

## 5. Expected Outcome
The system will generate a personalized fitness plan using Gemini AI based on the user's requirements.

## 6. Technologies
- Python
- Gemini API
- FastAPI
- HTML/CSS
- GitHub
